# Proofwork design system

## Direction

The quiet instrument, drawn with seed `27769804`. A paper and green palette replaces the previous dark interface presentation. The page's idea is that every recommendation has work behind it: the interface makes that evidence inspectable rather than centering a numeric verdict.

The visual system uses a broad, two-line hero with a supporting column, followed immediately by a working assessment example. Dark green evaluation and contact sections provide contrast; role selection, a session excerpt, and the candidate information each use a different composition.

One typeface: Schibsted Grotesk. Display type uses tight tracking and medium weight. Body text stays at 16px; compact interface excerpts use 13–16px. Section headings fit within two lines. The layout uses a 1200px maximum width with 20px phone gutters and larger fluid desktop gutters.

Page surfaces use flat color without gradients, resting shadows, decorative dividers, or glass. Product fragments are marked `data-ui` and retain functional separators, draft status, source labels, and selection states. Buttons have a consistent near-square shape and touch-safe feedback.

## Interaction

- Assessment stages reveal the task, approach, submitted result, and evaluation.
- Five dimension selectors expose a source excerpt, interpretation, and limitation.
- Role selectors show the matching pair of tasks.
- Native FAQ disclosures remain keyboard accessible.
- All demo actions use the same configured email destination.
- One-time section entrances animate opacity and transform. Content is visible if JavaScript fails. Reduced motion removes animation and smooth scrolling.

No stock photographs or generated pictures are used. Product interface examples are the imagery: the full assessment, session moments, and four small workflow fragments. Every assessment example is labeled as fictional. The founder identity uses initials, not an invented portrait.

## Content constraints

All five evaluation dimensions have equal standing. A single verification event is not a verdict on competence. Draft evaluation, reviewer override, participant disclosures, and consent remain explicit. Keep private pipeline mechanics, answer keys, and real candidate data out of marketing assets.
